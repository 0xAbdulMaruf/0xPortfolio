# Abdul MaruF - Offensive Security Portfolio

A high-fidelity, interactive cybersecurity portfolio built with Next.js, React 19, and Tailwind CSS v4.

## Getting Started

First, run the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Features
- **Next.js 16** App Router
- **React 19**
- **Tailwind CSS v4**
- **Framer Motion & GSAP** animations
- **React Three Fiber** for 3D components
